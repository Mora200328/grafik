ГРАФИКИ — приложение для расписания смен кофейни

СОДЕРЖИМОЕ
- index.html — само приложение
- manifest.webmanifest, service-worker.js, icon.* — файлы для установки на главный экран (PWA)

КАК ОТКРЫТЬ СРАЗУ
Можно открыть index.html в браузере на компьютере или телефоне. Для постоянной работы и установки как отдельного приложения лучше разместить всю папку на HTTPS-хостинге. HTTPS нужен для установки веб-приложения и офлайн-режима.

КАК УСТАНОВИТЬ НА ТЕЛЕФОН
1. Разместите ВСЕ файлы из этой папки на HTTPS-хостинге, сохраняя их рядом в одной папке.
2. Откройте HTTPS-адрес приложения на телефоне.
3. Android (Chrome): меню ⋮ → «Установить приложение» или «Добавить на главный экран».
4. iPhone (Safari): «Поделиться» → «На экран Домой».

КАК РАБОТАЕТ
- Добавление и удаление сотрудников.
- Календарь смен по дням.
- У каждой смены настраиваются дата, время начала и окончания.
- Для передачи смены добавьте две смены подряд (например, 08:00–14:00 и 14:00–21:00).
- Для обучения можно добавить второго сотрудника к той же смене.
- Проверяются пересечения смен.
- Экспорт текущего месяца в файл Excel (.xlsx).
- Работает без подключения к интернету после первого открытия на HTTPS-адресе.

ВАЖНО О ДАННЫХ
Сейчас данные хранятся локально в браузере/на устройстве, а не в общем облаке. Используйте одно и то же устройство и браузер, не очищайте данные сайта. Экспортируйте расписание в Excel для резервной копии. Если нужно пользоваться с нескольких телефонов с общей синхронизацией, потребуется серверное хранилище.
